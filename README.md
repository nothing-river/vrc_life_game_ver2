# VRC人生ゲーム
2〜4人用。静的ファイルのみ。GitHub Pagesで公開できます。
- 公開: Settings → Pages → Branch: main / root
- 写真はブラウザ内で120pxに縮小して駒に使うだけで、サーバーには送信されません。
- マスの並びは js/data.js の LAYOUT、効果は js/game.js の H で編集できます。

## オンライン対戦
トップ画面で「ルームを作る」→合言葉を決める→参加者に合言葉を伝える。参加者は「ルームに入る」で同じ合言葉を入力。
PeerJS(WebRTC)による端末同士の直接通信で、ホストの端末がゲームを進行します（ホストがページを閉じると終了）。

## ステージ構成
メインは外周ループ＋3か所の分かれ道（分岐→合流）。js/data.js の BRANCHES で道やマスの種類を編集できます。

## 調整ポイント
- お金の規模: js/data.js の `MONEY_SCALE`（大きいほど金額が増える）
- 配色: css/style.css 先頭の `:root` の変数

## 結果画面からの再戦
オンライン：結果画面の「ルームに戻る」を各自が押し、ホストが「ルームに戻って再戦する」を押すと、戻った人が同じ合言葉のルームに集まります。ロビーで名前・写真・ターン数などを変えて「この人数で開始」。

## プレイヤーの色
ルーム（ロビー）・同じ端末プレイ・ゲーム中のプロフィール変更で、カラーピッカーかRGBスライダーで色を指定できます。未指定ならデフォルト色（ピンク・水色・黄・緑）。デフォルト色は js/data.js の `COLORS`。

## 写真について
写真は保存していません。ブラウザ内で120pxに縮小して使うだけで、サーバーへの保存・アップロードはありません（オンライン時のみ同じルームの参加者の端末に直接送信）。ページを閉じると消えます。

## 画面構成・スマホ対応
- 画面上部の「ターンバー」に現在のターン数と手番のプレイヤーを常時表示。マスのイベント内容は別枠（イベント枠）に残ります。
- 盤面は横スクロール式。スマホでは手番の駒の位置へ自動でスクロールします。ログは直近300件を保持してスクロールで確認できます。
- 🌫️ 霧モード（ルーム作成/設定画面でON）：マスの約半分が「？？？」で、誰かが止まると全員に公開。🔭望遠鏡で5マス公開。
- 📄 離婚マス：結婚中／お砂糖あり／元お砂糖あり／どちらもなし、で別のイベントが起きます。

## PCの画面構成
幅1400px以上は「マップ｜操作｜ログ」の3カラム。それより狭いとログは操作の下、スマホは縦並びです。

## 画面の自動調整・演出
- PC(幅1000px以上)は、ブラウザの大きさ（ズーム含む）に合わせて、マップ・操作・ログが縦スクロール無しで収まるよう自動調整されます（4人プレイ前提で設計）。
- 手番の順番はログの上に固定表示。
- マスごとの演出と表示時間は js/game.js 先頭の `FX_INTRO` `FX_HOLD_MIN` `FX_HOLD_PER_CHAR` `FX_HOLD_MAX` で調整できます。

## 追加要素（2026.10.23-a）
- 対戦：⚔️対戦マス（ダイス勝負／チンチロ／ハイ&ロー／反応速度／連打）、💘お砂糖の略奪、🔗同盟（裏切りあり）、🔎探偵、🏛️税金・寄付
- アイテム：🦹泥棒 🚫ブロック 🔇ミュート 🔄位置入れ替え（使ってもサイコロは振れる）、🛡️ガード（自動で1回防ぐ）
- VRChatネタ：🏗️制作投資（印税）、🎪集会の常連、👗着せ替え、🚨通報・BAN、🌐同じマスで交流、🌐全体イベント、🃏ギャンブル／借金
- お砂糖：好感度・性格・記念日・多糖の隠し・結婚式のブーケ
- 開始時に職業を選択／隠しミッション／ルーム作成時のハウスルール（初期所持金・対戦の有無・全体イベント・ミッション）
- js/extra.js に追加機能がまとまっています。マスの並びは js/data.js、金額は MONEY_SCALE。

- 対戦マス・略奪・探偵・同盟の相手や、対戦ゲーム・賭け金はランダムで決まります。ダイス勝負・チンチロは各自が「振る」ボタンを押して進めます（反応速度・連打・ハイ&ローも各自が操作）。

## 効果音・BGM（2026.10.24-a）
- 効果音は `audio/se/`、BGMは `audio/bgm/` にファイルを置きます。ファイル名の一覧は各フォルダの README.txt と `js/audio.js` の `AUDIO_FILES` にあります。
- ファイルが無い音は、内蔵の簡易な音（効果音・BGM）が自動で鳴ります。右上の🔊🎵⚙で、オン/オフと音量を変えられます（端末に記憶されます）。
- 全体イベント中は、ログ欄の上に固定表示されます。対戦中は、参加していない人にも進み具合が表示されます（観戦）。
